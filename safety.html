Designed against abuse

Useful for self-audits.
Not a request cannon.

The scanner is deliberately slower and narrower than a generic scraping proxy. Every request is bounded before it leaves the service.

✓

Three-alias hard limit

The limit is enforced in the browser, Edge Function and database records, not just suggested in the interface.

✓

Allowlisted destinations

Users submit platform IDs, never URLs. Custom targets, private network addresses, arbitrary methods and redirect chains are rejected.

✓

Bounded concurrency

Checks run in small resumable server-side chunks with strict timeouts. Closing the browser does not cancel the job, and each chunk remains bounded.

✓

Request budgets

Per-client and global limits restrict scan creation, batch size and total requests. Suspicious or oversized payloads are refused early.

✓

Minimal retention

Scan records expire within 24 hours. Email addresses are removed after delivery and are never added to a marketing list.

✓

Public data only

The service does not log into platforms, bypass access controls or attempt to retrieve private profiles. Important matches must be verified at the linked source.

✓

Human-controlled claiming

Username Sniper checks fixed public profile locations, then opens official signup pages. It never creates accounts, handles passwords, solves CAPTCHAs or bypasses platform protections.
