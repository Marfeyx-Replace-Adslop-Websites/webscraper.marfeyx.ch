How it works

A careful search, not digital divination.

Every result keeps its source and confidence visible.

01

Normalize

Aliases are validated locally. Arbitrary URLs, domains and request payloads are never accepted.

02

Verify

Allowlisted profile or public API endpoints are checked in small, delayed batches with strict timeouts.

03

Enrich

Supported platforms add public activity counts and recent content. Private or gated data stays untouched.

04

Report

Confirmed, uncertain and failed checks remain separate, then the report expires automatically.
